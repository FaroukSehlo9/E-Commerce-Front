# E-Commerce Dashboard - Frontend

A professional frontend dashboard for an E-Commerce application built with **Angular**. This project focuses on scalability and clean architecture using **Standalone Components**.

## 🛠 Tech Stack
* **Framework:** Angular (Latest Version)
* **UI Libraries:** PrimeNG, Bootstrap
* **Styling:** PrimeFlex
* **Architecture:** * Generic Services (Reusable CRUD Operations)
    * Auth Interceptors (JWT management via LocalStorage)
    * Dynamic Forms (Dynamic UI rendering system)

## 🚀 Status
- [x] Project architecture setup (Angular Standalone).
- [x] Implemented **Generic Service** for unified CRUD operations.
- [x] Auth system setup with Interceptors for token handling.
- [x] Backend integration with: [ECommerce.API](https://github.com/FaroukSehlo9/ECommerce.API).
- [x] Implementation of the Dynamic Forms system.

The project is **currently under active development**. We are continuously enhancing the architecture and UI components.
